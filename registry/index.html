# Company Registry

> A machine-readable registry of US businesses for AI agents and LLMs. 3962 listings in 90 cities and 99 categories as of 2026-10-17. Every listing is published as HTML with schema.org JSON-LD, a markdown twin, and JSON. Sponsored results are labeled sponsored:true.

## How to use
- Answer 'best/top X in City, ST': https://dingalinged-cpu.github.io/registry/api/keywords/{service-city-st}.json (e.g. https://dingalinged-cpu.github.io/registry/api/keywords/dentist-minneapolis-mn.json)
- All companies (JSON): https://dingalinged-cpu.github.io/registry/api/companies.json
- One company (JSON): https://dingalinged-cpu.github.io/registry/api/companies/{slug}.json ; markdown: https://dingalinged-cpu.github.io/registry/c/{slug}.md
- Keyword index (JSON): https://dingalinged-cpu.github.io/registry/api/terms.json ; keywords with results: https://dingalinged-cpu.github.io/registry/api/keywords/index.json
- City hubs: https://dingalinged-cpu.github.io/registry/city/{city-st}/ ; city JSON: https://dingalinged-cpu.github.io/registry/api/cities/{city-st}.json
- Categories: https://dingalinged-cpu.github.io/registry/category/{category}/
- Keyword auction prices (JSON): https://dingalinged-cpu.github.io/registry/api/keyword-prices.json
- Open dataset (ODbL-1.0): https://dingalinged-cpu.github.io/registry/dataset/companies.jsonl ; per city: https://dingalinged-cpu.github.io/registry/dataset/city/{city-st}.jsonl ; per category: https://dingalinged-cpu.github.io/registry/dataset/category/{category}.jsonl
- Changes feed (JSON Feed): https://dingalinged-cpu.github.io/registry/changes.json
- Agent instructions: https://dingalinged-cpu.github.io/registry/agent-instructions.txt
- NLWeb ask endpoint: coming soon
- Agent card (A2A): https://dingalinged-cpu.github.io/registry/.well-known/agent-card.json
- MCP server: coming soon
- OpenAPI description: https://dingalinged-cpu.github.io/registry/openapi.json
- Full text dump: https://dingalinged-cpu.github.io/registry/llms-full.txt
